Ragnar — Configuração de Ambientes

Referência operacional: desenvolvimento local vs produção (VPS). Documento base para a documentação final do projeto.

Repositório: RN3-Alexandre-Nordin/ragnar · Versão do doc: jun/2026 · Não commitar segredos neste arquivo.

Regra de ouro: nunca misturar credenciais entre ambientes. Dev usa Supabase ragnar-dev + Evolution evo-dev. Produção usa Supabase prod + Evolution prod + domínio app.ragnar.ia.br.

1. Visão geral

Desenvolvimento

Onde roda

PC local — npm run dev

RAGNAR_ENV: development

Arquivo de env: .env.local (gitignore)

Branch Git: develop

Produção

Onde roda

VPS — Docker Compose + Traefik

RAGNAR_ENV: production

Arquivo de env: /opt/ragnar/.env

Branch Git: main (CI/CD deploy)

Fluxo de mensagens (omnichannel)

WhatsApp cliente → Evolution API (VPS dev ou prod) → Webhook HTTPS Ragnar → Supabase (projeto do ambiente) → Chat / IA Gemini

Prioridade de leitura (código)

Arquivo: src/lib/config/environment.ts

  • RAGNAR_ENV explícito vence sobre NODE_ENV
  • Em dev, buildEvolutionProviderConfig força credenciais *_DEV do env (não usa token clonado do canal no DB)
  • Sufixos: WHATSAPP_API_URL_DEV|PROD, WHATSAPP_API_TOKEN_DEV|PROD, RAGNAR_WEBHOOK_URL_DEV|PROD

6. Túnel Cloudflare (dev local)

A Evolution na VPS não alcança localhost. Use túnel HTTPS público.

ComandoFunção
npm run tunnel:setupConfiguração inicial Cloudflare
npm run tunnel:fixedTúnel nomeado (hostname fixo)
npm run tunnelTúnel temporário (trycloudflare)

Hostname fixo documentado: ragnar-local.rn3.tec.br → apontar em RAGNAR_WEBHOOK_URL_DEV.

Config exemplo: cloudflared/config.example.yml (credenciais em cloudflared/config.yml, gitignore).

8. Checklist de conferência

Desenvolvimento (antes de testar WhatsApp local)

  • .env.local com RAGNAR_ENV=development e Supabase dev
  • WHATSAPP_API_TOKEN_DEV válido para evo-dev
  • Túnel Cloudflare ativo (npm run tunnel:fixed) e RAGNAR_WEBHOOK_URL_DEV apontando para o hostname público
  • Webhook registrado na instância Evolution dev
  • npm run dev rodando; logs mostram Supabase dev (vujqukqsfwmoezwyuoum)
  • Migration crm_conversas_one_row_per_message aplicada no Supabase dev
  • Chat omnichannel carrega conversas; Realtime ou polling ativo

Produção (antes de go-live / após deploy)

  • DNS app.ragnar.ia.br aponta para VPS prod
  • Traefik com certificado TLS válido para app.ragnar.ia.br
  • /opt/ragnar/.env com URLs prod (app.ragnar.ia.br, não domínios antigos)
  • Supabase prod — migration sessao_id aplicada
  • Evolution prod — webhook = https://app.ragnar.ia.br/api/webhooks/evolution
  • Instância WhatsApp prod conectada; canal crm_canais com provider_id correto
  • GitHub Actions verde; container docker ps saudável na VPS
  • GET /api/health/omnichannel → healthy: true, environment: production
  • Login cockpit prod; mensagem WhatsApp teste grava em crm_conversas / crm_interacoes
  • Assinatura WhatsApp (bolha 🤖 Agente de IA) visível no celular do cliente
